# ms-chamados 1.0.0-beta.2

> **Pré-lançamento (pre-release):** funcional e em testes. Segue o [Versionamento Semântico 2.0.0](https://semver.org/lang/pt-BR/).
> Data: 2026-11-25

### Alterado
- **Papéis alinhados ao Thindesk** (`ROOT › ADMIN › TECNICO › USUARIO`): `ROLE_ROOT` passa a ter poderes de técnico
  (listar de qualquer usuário, fila de abertos e resolver). Antes um token só com `ROLE_ROOT` era tratado como usuário comum.
- `@PreAuthorize` de `/abertos` e `/{id}/resolver` aceita `TECNICO`, `ADMIN` e `ROOT`.

**Histórico completo:** https://github.com/MiguelSantanaDaCosta/-Microservi-o-de-Chamados-T-cnicos-/compare/v1.0.0-beta...v1.0.0-beta.2
